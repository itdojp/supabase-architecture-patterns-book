## 3. 構成上の気になる点（候補）

- 入口不整合: `README.md` が書籍ではなくテンプレート説明になっている。
- ライセンス表記の不整合: `docs/index.md` と `docs/introduction/index.md` と `LICENSE.md` の整合が取れていない（要確認）。
- 章タイトル/章番号の見せ方:
  - `docs/index.md` では「第5章」が3行（5-1/5-2/5-3）で並んでおり、読者が「第5章は1つなのか、3章相当なのか」を誤解しやすい。
  - front matter の `title:` と本文H1（`# Chapter n: ...`）の表記が混在しており、引用や検索で揺れやすい。
- 章内の重複・番号不整合の疑い:
  - 第5章-3に `まとめ` が複数回出現している。
  - 第8章に `8.2` の重複や `トラブルシューティング` の重複が見える。
  - 第9章に `9.2` が複数回出現している。
  - これらは「導入→本論→まとめ」の流れを追いづらくし、章内参照を阻害する可能性がある。

## 4. 構成改善の提案（案）

- 入口の確定:
  - `README.md` を「読者入口」にし、`docs/index.md` と同一の書名/概要/オンライン版リンク/ライセンスに整合させる。
- ライセンス表記の統一（優先度: 高）:
  - どのライセンスを採用するかを確定し、`docs/index.md` / `docs/introduction/index.md` / README / `LICENSE.md` の表記を統一する（要確認）。
- 章番号の整理:
  - 第5章（5-1/5-2/5-3）は「第5章-1」等の表記に揃える、または章番号を振り直して「第5章〜第7章相当」にする等、読者が迷わない表現にする。
  - 第5章-3 / 第8章 / 第9章の見出し番号重複は、見出し番号のみを機械的に修正して参照性を回復する（内容は不変更）。
- 章テンプレート（導入→本論→まとめ）の強化:
  - 各章の「この章で学ぶこと」→「本論」→「まとめ」→「次章予告」を共通化し、章間の読み進め方を固定化する。
- 用語/表記の整合（将来のStage3候補）:
  - 絵文字・比喩の使い方、英日混在の表記（`Chapter`/`第X章`）は、シリーズのスタイル方針に合わせて統一可否を検討する。
